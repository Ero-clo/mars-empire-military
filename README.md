# 火星帝国军事部门（10 人在线身份游戏）

## 功能
- 10 人同房间联机，支持不同地区、手机和电脑浏览器。
- 房主创建房间后可复制邀请链接或分享 5 位房间码。
- 必须满 10 人且所有玩家准备后才能开始。
- 服务器随机分配 2 名间谍、8 名平民；身份通过私密事件发送给对应玩家。
- 房主可重新开局；玩家退出会触发本局重置。

## 本地运行
需要 Node.js 18 或更新版本。

```bash
npm install
npm start
```

浏览器打开 `http://localhost:3000`。

## 发布到互联网（例如 Render）
1. 将整个项目上传到自己的 GitHub 仓库。
2. 在 Render 创建一个新的 Web Service，并连接该仓库。
3. Build Command 填：`npm install`
4. Start Command 填：`npm start`
5. 发布完成后会获得一个 `https://....onrender.com` 网站地址。
6. 把网站地址发给玩家。房主创建房间后，再分享页面中的邀请链接。

## 注意
- 这是可运行的基础版本；房间数据存储在服务器内存中。服务器重启后房间会消失。
- 不要把此版本用于真实机密信息。它是派对游戏，不是安全通信系统。
- 如果以后要支持聊天、投票、游戏记录、账号系统或长期保存房间，需要继续开发。
